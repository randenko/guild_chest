## Mod changes

- Guild chests now have a warm gold tint, large gold coin seals and smaller coin studs on both faces, and five coins across the lid. The decorations follow the open and closed lids. ([#9](https://github.com/randenko/guild_chest/pull/9))

## Other changes

- Move development builds, tests, packaging, and GitHub workflows to a shared, pinned NUKE build runner. Improve custom game-reference support and add build regression tests. ([#6](https://github.com/randenko/guild_chest/pull/6))
- Add and fix README badges for CI, the latest release, and the license. ([#5](https://github.com/randenko/guild_chest/pull/5), [#8](https://github.com/randenko/guild_chest/pull/8))
- Set the dev container timezone to America/New_York. ([#7](https://github.com/randenko/guild_chest/pull/7))
- Keep release notes in the repository and require separate Mod changes and Other changes sections for every future release.
