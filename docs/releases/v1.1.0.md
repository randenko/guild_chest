# Guild Chest 1.1.0

## Mod changes

- Remove legacy spill-recovery handling for worlds saved by releases that dropped
  shared contents when the final chest was destroyed. Current final-chest
  retention remains unchanged: contents stay in the world save and can be
  accessed by rebuilding a Guild Chest, including after a restart with no chests.

## Other changes

- Prepare the Thunderstore launch under Paper_Street_Software, with reviewed
  GitHub release assets, checksum validation, read-only preflight, and serialized,
  retryable uploads using the official pinned tcli 0.2.4.
- Make the README the player listing, move build/setup instructions to the
  development guide, and document installation, configuration, compatibility,
  backups, removal, and recorded validation limits.
- Add GitHub bug and feature-request forms as the exclusive tracking channel.
- Add presentation screenshots, a video thumbnail, and a ready-to-paste YouTube
  description; keep media outside the mod ZIP.
- Generate the packaged changelog from these notes and make packaged listing
  links point to this release. Extend package and publisher regression tests.
- Use feature releases X.Y.0 and bugfix releases X.Y.Z, retaining published 1.0.12
  history. Mixed releases follow the feature-release rule.
- Guild Chest is free and open source. Enjoying the mod?
  [Buy me a coffee](https://ko-fi.com/randenko) as an optional thank-you.
