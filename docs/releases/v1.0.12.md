## Mod changes

- Preserve all shared items when the last guild chest is destroyed. Only construction materials drop; rebuild a guild chest in the same world to retrieve the contents, even after saving and restarting with no chests. Item metadata is retained. ([#14](https://github.com/randenko/valheim-guildchest/pull/14))
- Mount gold coin decorations flush against the chest's panels and lid, removing the visible gaps. ([#13](https://github.com/randenko/valheim-guildchest/pull/13))
- Place the guild chest immediately after the reinforced chest in the hammer menu. Its icon now shows the gold tint and coin decorations, facing left at an angle consistent with the vanilla chest icons. ([#17](https://github.com/randenko/valheim-guildchest/pull/17))
- Change the BepInEx plugin ID to `randenko.GuildChest`, with configuration stored in `BepInEx/config/randenko.GuildChest.cfg`. ([#16](https://github.com/randenko/valheim-guildchest/pull/16))

## Other changes

- Add regression coverage and a disposable-world native fixture for final-chest inventory retention, save/restart, rebuilding, lease revocation, and preserved item metadata. Update architecture and gameplay validation documentation.
- Install Bubblewrap and allow the namespace calls needed by the Codex sandbox in the dev container. Document container setup and sandbox verification. ([#15](https://github.com/randenko/valheim-guildchest/pull/15))
- Update the README title, badges, and links for the repository rename to `randenko/valheim-guildchest`. ([#18](https://github.com/randenko/valheim-guildchest/pull/18))
